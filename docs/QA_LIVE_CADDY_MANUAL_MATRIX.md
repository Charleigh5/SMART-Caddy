# Live Caddy Manual QA Matrix - Phase 5.9

> **DEPRECATED**: Human-readable reference only. Canonical executable QA matrix lives in `src/lib/manualQaMatrix.ts`.

This document outlines the required manual Quality Assurance checks to be run on actual physical devices and real browsers. Automation currently verifies standard happy/unhappy paths, but physical testing is required to transition features from `PARTIALLY_VERIFIED` to `VERIFIED`.

## Required Devices / Platforms

1.  **Desktop - Chrome** (Latest)
2.  **Desktop - Edge** (Latest, if available)
3.  **Mobile - Safari/iOS** (Latest, mandatory to verify fallback/degraded behaviors)
4.  **Mobile - Android Chrome** (Latest, mandatory for permissions testing)
